## 一个被低估的难题：识别 28×28 的手写数字

一张 28×28 像素、字迹歪斜的低分辨率图像，人脑几乎不费力就判断出它是 3。值得停下来惊叹一下这件事的难度：不同人写的三个"3"，逐像素比较几乎毫无共同之处，你视网膜上被激发的感光细胞集合天差地别，但视觉皮层中一小块区域却能把它们归结成同一个信息，同时又把别的图像区分成各自不同的信息。

反过来，如果要求你手写一个程序：输入一个 28×28 的灰度值表格，输出 0 到 9 之间的一个数字，这个"轻松"的任务立刻变得极其棘手。你无法枚举所有写法，也很难用显式规则描述"什么算一个圈"。

- 本文只讨论最朴素的原味版本——**多层感知器（MLP）**，不加任何现代技巧
- 神经网络的变种极多，但先理解经典结构，才谈得上理解更强大的现代变种
- 即便是这个最简单的版本，用来识别手写数字已经效果不错；同时它也会在某些地方表现得不尽如人意

## 神经元、层与激活值

"神经网络"的名字来自大脑结构，但要理解它，先把神经元想象成一个**装数字的容器**：里面装着一个 0 到 1 之间的数，仅此而已。这个数叫做**激活值**（activation），可以想象激活值越大，神经元就点得越亮。

**输入层**：28×28 = **784 个神经元**，每个对应图像的一个像素，装的就是该像素的灰度值——0 表示纯黑，1 表示纯白。这 784 个神经元构成网络的第一层。

**输出层**：**10 个神经元**，分别代表数字 0 到 9，激活值同样在 0 到 1 之间，表示系统认为输入图像是这个数字的可能性。最亮的那个神经元就是网络的"选择"。

**隐含层**：中间几层，暂时当成黑箱，识别数字的实际工作在这里发生。这里选择 **2 层隐含层、每层 16 个神经元**。要坦白的是，这些数字是随意选的：两层的理由后面会解释，16 纯粹是画出来好看。实际应用中，网络结构有很大的实验和调整余地。

网络的核心机制就是：**上一层的激活值决定下一层的激活值**。这在模仿生物神经网络中某些神经元的激发促使另一些神经元激发的现象。

所谓"这个网络已经训练好了，能识别数字"，意思是：当你把某张图的 784 个灰度值灌进输入层，这一层的激活值图案会在下一层引发某种特定图案，再引发再下一层的图案，最终在输出层点亮某一个神经元。

## 为什么层状结构可能带来"智能"：分层抽象的设想

在讲清数学之前，先问一个更根本的问题：凭什么这种层状结构能做出智能判断？我们希望中间层做什么？

人类识别数字时，是在**组合部件**：9 是上面一个圈加右边一竖；8 是上面一个圈搭着下面一个圈；4 可以拆成三条直线。

**理想中的倒数第二层**：每个神经元对应一个笔画部件。输入带圈的 9 或 8 时，某个"顶部圆圈"神经元的激活值接近 1——注意这里不特指某种具体形状的圈，而是希望所有位于图像顶部的圆圈图案都能点亮它。这样从倒数第二层到输出层，网络只需要学"哪些部件组合出哪个数字"。

**再往前一层**：识别圆圈本身还可以继续拆分。合理的做法是先识别更小的**边**。像 1、4、7 里的长条就是一条长边，也可以看成几条短边的组合。于是我们希望第二层的神经元对应各种各样的短边：某种图像输入进来，把八到十个相关短边的神经元点亮，进而点亮"顶部圆圈"和"长竖条"的神经元，最后点亮代表 9 的输出神经元。

这套设想同时也解释了这种结构为什么值得期待：**能识别边缘和图案的能力可以迁移到别的任务上**。世界上大量人工智能任务都可以转化为一层层抽丝剥茧的抽象。比如语音识别，就是从原始音频中识别特殊的声音，组合成音节，组合成单词，组合成短语，再到更抽象的概念。

不过要诚实地说：这只是我们的**希望**。网络训练完是否真的形成了这样的分层表示，要等讲完训练原理再回头讨论。而"如何识别这些部件""哪些部件才算正确的"这些问题，此时也都还悬着。

## 一个神经元的计算：权重、加权和、偏置、sigmoid

现在设计具体机制：上一层的激活值如何决定下一层的激活值？聚焦第二层中的某一个神经元，目标是让它识别图像某块区域里是否存在一条边。

**第一步：赋权重求和。** 给这个神经元与第一层全部神经元之间的每条连线各赋一个**权重**——权重就只是数字。把第一层所有激活值与对应权重相乘再相加，得到**加权和**。

把权重摆成一张 28×28 的表格来看更直观：正权重画成绿色，负权重画成红色，颜色越暗表示越接近 0。

- 若把关注区域的权重设为正值、其他所有权重设为 0，那么加权和就只累加关注区域的像素亮度
- 若想真正检测"这里有一条边"，还要给关注区域周围一圈像素赋**负权重**。这样只有当中间像素亮、周围像素暗时，加权和才达到最大

**第二步：压缩到 0 到 1。** 加权和可以是任意大小，但我们要求激活值落在 0 到 1 之间。于是把加权和送进一个把整条实数轴挤压进 [0, 1] 的函数。常用的是 **sigmoid 函数**（又叫 logistic / 逻辑斯蒂曲线）：非常大的负值被压成接近 0，非常大的正值被压成接近 1，在 0 附近平稳增长。

于是这个神经元的激活值，本质上是**对"加权和有多正"的一个打分**。

**第三步：加偏置。** 有时加权和大于 0 你仍然不想让神经元点亮，比如希望只有超过 10 才激发。做法是在加权和之后加上一个 −10 之类的数，再送进 sigmoid。这个附加的数就叫**偏置**（bias）。

一句话总结这两类参数的分工：

> **权重**告诉你这个神经元关注什么样的像素图案；**偏置**告诉你加权和得有多大，神经元的激发才算有意义。

## 一万三千个旋钮：参数规模与"学习"的含义

上面只讲了一个神经元。而这一层的每个神经元都与第一层全部 784 个神经元相连，各自有 784 个权重、各自有一个偏置，各自算完加权和加偏置后再过 sigmoid。

- 第一层到第二层：784 × 16 个权重 + 16 个偏置
- 加上后面各层之间的连接及其自带的权重与偏置，整个网络一共约 **13000 个权重和偏置**
- 相当于这台机器上有一万三千多个旋钮可以调，每种调法给出不同的行为

所以，**当我们说"机器学习"时，实质在说：计算机该如何设置这一大堆数字参数，才能正确解决问题。** 一个细思极恐的思想实验是：想象你自己动手拧这一万三千个旋钮，逼着第二层去识别短边、第三层去识别图案。

为什么值得这样思考，而不是把网络当纯黑箱？因为当输出与期望不符时，如果你对权重和偏置的意义有一定理解，修正结构就有了出发点。另一种情形是：网络给出了正确结果，但内部过程和你想象的完全不同——去深挖权重和偏置的实际含义，可以有效地挑战你的假设，进而探索出更多可能的解决方案。

## 用矩阵把整层写成一行

把上述计算逐个连线写成公式会非常笨重。标准做法是用线性代数的记号，这也是你之后学习神经网络时会反复见到的写法：

1. 把某一层所有激活值排成一个**列向量**
2. 把这一层到下一层的所有权重放进一个**矩阵**：矩阵第 n 行是本层所有神经元与下一层第 n 个神经元之间连线的权重
3. 于是**权重矩阵乘激活值向量**，其结果的第 n 项，正好就是下一层第 n 个神经元所需的加权和
4. 把所有偏置也放进一个**向量**，与矩阵乘法的结果相加
5. 最后用 sigmoid 把整个表达式"包起来"——即对结果向量的每一项分别取一次 sigmoid

写下来就是一行：**下一层激活值 = sigmoid(权重矩阵 × 本层激活值 + 偏置向量)**。

这种表达不只是好看。它让程序实现简便得多，因为许多数值库（例如 numpy）对矩阵乘法做了充分优化。顺带一提：机器学习到头来和线性代数不分家，如果想更形象地理解矩阵与矩阵乘法的意义，可以去看"线性代数的本质"系列，尤其是第三章。

## 重新理解：神经网络就是一个函数

前面让你把神经元看作装数字的容器，现在可以修正这个说法。神经元里装的值取决于输入图像，所以把神经元看作一个**函数**更准确：它接收上一层所有神经元的输出，返回一个 0 到 1 之间的值。

推而广之，**整个神经网络就是一个函数**——输入 784 个值、输出 10 个值。只不过这个函数极其复杂：它用了约 13000 个权重与偏置参数去识别特殊图案，反复做矩阵乘法和 sigmoid 映射。但它终究只是个函数。

它的复杂反而让人安心：如果它没有这么复杂，我们大概也没法指望它把手写数字识别得多准。

剩下的核心问题是：它如何完成这项艰巨任务？网络如何**从数据中获得**合适的权重和偏置？这属于学习（训练）的部分。

## 补充：从 sigmoid 到 ReLU

一段与深度学习理论研究者 Lisha Li 的对谈补充了历史脉络：

- 早期网络普遍用 sigmoid 把加权和映射到 0 至 1 区间，正是为了模仿生物神经元"是否激活"这一现象
- 现在的网络基本不再用 sigmoid，**ReLU 更容易训练**
- **ReLU**（线性整流函数）的定义极简单：返回 0 和输入 a 之间的最大值。超过阈值时它等同于恒等函数，未过阈值就输出 0，可以看作一种简化版的"激活/不激活"
- 这种简化本身并不意味着结果更好，sigmoid 的问题更在于难训练；后来有人在**特别深**的网络上试用 ReLU，发现效果特别好
